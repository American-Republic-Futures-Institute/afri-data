## Preflight outputs and limitations

Even a locally present CODEOWNERS file is not evidence that GitHub actually enforces its rules. An online GitHub 403, absent CODEOWNERS, missing reviewer, unrecorded method review, insufficient branch protection or mismatched source hash results in a blocked state. The preflight does **not** activate GitHub controls.

The actual connected GitHub integration returned no repository rulesets and 403 on `branches/main/protection` during this increment; `.github/CODEOWNERS` was absent and the policy remained empty. No direct attempt has been made to forge a reviewer or to make a change to a protected-branch setting using unsupported permissions.

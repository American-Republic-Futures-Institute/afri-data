# Review-gated publication directory

Actual government-derived assets are written here only after source downloads, integrity checks and human release review.

- The Census ingestion workflow writes a proposed publication to a review branch/PR.
- Validation rejects missing geographies, altered source bytes, invalid geometries and mismatched asset checksums.
- Unreviewed synthetic test fixtures are never committed here.
- Published assets are consumption inputs for the ARFI website, not an assertion of institutional policy.

See ../docs/OPERATIONS.md and ../docs/WEBSITE-INTEGRATION.md.
